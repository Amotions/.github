# Amotions AI

Amotions AI is a real-time AI sales coach. It privately listens to live Zoom, Teams, Google Meet, and phone calls and suggests what to say next, without joining as a bot. Reps rehearse with AI roleplay before calls and get post-call scorecards after. Built by Amotions, Inc. in Burlingame, California.

## Remote MCP Connector (`https://amotionsinc.com/mcp`)

Amotions AI hosts a read-only **Model Context Protocol (MCP)** remote server over Streamable HTTP with OAuth 2.1 PKCE at `https://amotionsinc.com/mcp` (discovery metadata at `https://amotionsinc.com/.well-known/mcp.json`).

Connect your assistant to inspect **only your own** Amotions call scores, post-call coaching takeaways, transcripts, score trends, and next-call coaching focus areas:

| Assistant | Workflow Overview | Setup Guide |
| --- | --- | --- |
| **ChatGPT** | https://amotionsinc.com/integrations/chatgpt | https://amotionsinc.com/docs/use-amotions-in-chatgpt |
| **Claude** | https://amotionsinc.com/integrations/claude | https://amotionsinc.com/docs/use-amotions-in-claude |
| **Perplexity** | https://amotionsinc.com/integrations/perplexity | https://amotionsinc.com/docs/use-amotions-in-perplexity |
| **Grok** | https://amotionsinc.com/integrations | https://amotionsinc.com/docs/use-amotions-in-grok |

See [**Amotions/amotions-mcp**](https://github.com/Amotions/amotions-mcp) for tool schemas, OAuth discovery endpoints, and MCP client configuration.
